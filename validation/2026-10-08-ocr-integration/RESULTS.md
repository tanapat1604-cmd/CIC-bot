## Limits, cancellation and privacy

Only actual static PNG8bit (gray/RGB/RGBA supported types) or JPEG8bit; no SVG/GIF/APNG/TIFF, no EXIF rotation. Bytes4MiB,4M pixels, side4096,3 integer in-image ROIs, processed crop8M pixels,8000 text chars/4000 words,16 RAM metadata jobs,20s manager deadline. Actual bytes/header validated before decoding; Pillow repeats format/dimension/decode checks, PNG chunk CRC/IEND/trailing data checked, JPEG must end at EOI. Filename/MIME is not trusted. Client rejects invalid ROI before submitting. One OCR worker, guarded at256MiB free RAM, mutually excluded with CIC model/chess/slides compute. This guard is a floor, not a total memory guarantee.

Generated private UUID directories only under ignored .cic-user-files/ocr. No client paths or shell. Base64 is NOT persisted in request metadata. Selected source image and intermediate crops/text/TSV exist on disk only while the worker runs; normal ready/error/cancel files are removed BEFORE publishing the result, verified with the native runtime. No image/text logging by default; stderr is discarded and errors allowlisted. Results/text/provenance remain in service RAM up to10min or until clear/service close. Browser selection/object URL stays until clear/replace/route leave; explicit reference retains reviewed text in that chat's in-memory state until removed/session/app close. Removing a chat reference does not instantly clear the server's ready metadata; its10min expiry applies. Refresh does not create a persistent archive. Abrupt service/power loss can leave ignored temp files; no crash-orphan recovery is implemented. Operator must inspect known OCR temp root before cleanup, never arbitrary user paths.

Cancel-before-create uses owner+operation reservations. Worker cancellation signals its owned process; native test waited for a live Tesseract PID, cancelled, verified process gone and temp folder empty. Fake uncooperative executor test verifies stop-unverified retains the compute lock, hides late results, and only releases after actual exit. Cleanup failure blocks new compute. Stop UI alone is not proof of process exit. Changed image/language/ROI, pending cancellation, route leave, stale status response and late create/result are covered. Reference IDs are session-owned; forged/expired refs cannot be used. Long OCR references may exceed the unchanged2048-token model context and return a clear error; never silently truncate or claim understanding.
