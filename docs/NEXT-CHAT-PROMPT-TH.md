# พรอมป์ต์เริ่มแชตใหม่

คัดลอกข้อความด้านล่างไปใช้ได้เลย

```text
ทำ CiC Bot ต่อจากrepoจริงที่เปิดอยู่ ถ้าเป็นเครื่องเดิมคือ D:\CIC bot\CIC-bot
อ่าน AGENTS.md แล้วอ่าน validation/CIC-CURRENT.md ถ้ามี มิฉะนั้นอ่าน docs/CIC-CURRENT.md และรายงานล่าสุดที่อ้างถึงก่อน
รักษาuncommittedทั้งหมด และsources/ในprojectmirrorเป็นอ่านอย่างเดียว
ฝึกจริงครบ100คลิปคนไม่ซ้ำแล้ว ไทย50อังกฤษ50 และทดลองเพิ่ม20epochsบน100เดิมแล้ว ยังถูก1/5ในชุดพัฒนา คำหยุดยังผิด จึงไม่promote อย่าเริ่มฝึก100ใหม่เพียงเพราะขึ้นแชตใหม่ ตรวจhash/pointer/optimizer/runtimeที่ใช้จริงก่อน
เน้นการฝึกและความเข้าใจAIก่อน เลือกสมมติฐานใหม่จากสาเหตุ ไม่เพิ่มรอบเดิมแบบสุ่ม ไม่ฝึกdevelopment/held ไม่เดาแก้คำถอดเป็นคำสั่ง เป้าจริง1–2วินาทีจากผู้ใช้พูดจบถึงคำตอบ/งานที่ถูก ผู้ใช้กดเริ่มไมค์เอง
เปิดทุกแอปเป็นเป้าหมายต่อไป แต่ให้ระบุแอปที่ตรวจผ่านจริง Chromeต้องหน้าต่างส่วนตัวเดิม TikTokยังไม่ผ่านnative-unverified และNotepadจากเสียงยังมีรายงานเปิดไม่ได้
งานหนักทีละงานผ่านbackendที่มีowner/session/nonce ตรวจStopจนchildออกจริง คืนค่าเดิม ไม่ปิดแอปผู้ใช้ ไม่global-kill ไม่ซื้อ/resetเครดิต ไม่สร้างautomation
ลดงานและเครดิตที่เปลือง: อ่านจุดต่อสั้นก่อน ใช้รายงานล่าสุด/ผลเดิม/cacheที่ตรวจhashแล้ว ไม่โหลดโมเดลหรือข้อมูลซ้ำ ไม่ทดสอบเดิมซ้ำถ้าไม่มีการเปลี่ยนแปลงหรือเหตุสงสัย บันทึกcheckpointทุกขั้นพร้อมpassed/failed/not-run
ลงมือทำและตรวจผลจริงก่อนรายงาน อัปเดตREADME+จุดต่อ+หลักฐานที่ไม่เผยข้อมูลส่วนตัวให้แชตใหม่ทำต่อได้ ซอร์สขึ้นGitHubได้ตามคำสั่งล่าสุด แต่ห้ามอ้างว่าผ่านทั้งหมดหรือmerge/deployรุ่นใช้งานจริงจนตรวจรับจริง
```
